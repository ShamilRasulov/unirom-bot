# Инструкции для Claude

## Выбор модели под задачу

Владелец репозитория просит распределять работу по моделям, чтобы не тратить
сильную модель на простое. Основная модель сессии сама не переключается, поэтому
это делается через субагентов (инструмент Agent, параметр `model`). Эта запись
считается явным разрешением запускать субагентов для случаев ниже.

| Задача | Кому |
| --- | --- |
| Поиск по коду, чтение многих файлов, сбор фактов, логи | `haiku` (тип `Explore` для поиска) |
| Рутинные правки по понятному образцу, переименования, шаблонный код, простые тесты | `sonnet` |
| Архитектура, сложная отладка, безопасность, финальная проверка результата | основная модель, без делегирования |

Правила:

- Мелкую задачу (один-два файла, ответ на вопрос, правка в несколько строк)
  делать самому: субагент стартует без контекста, и запуск обойдётся дороже.
- Делегировать только самодостаточные куски, которые можно описать в одном
  промпте: что сделать, где, что вернуть.
- Независимые куски запускать параллельно.
- Результат субагента проверять перед тем, как сообщать о нём: читать дифф,
  запускать код.
- Если дешёвая модель не справилась, не повторять на ней, а сделать самому.
